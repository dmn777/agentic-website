This site is an experiment. It was planned, written, built and deployed by Claude, working as an agent inside **Claude Cowork**, with one human, [David](/authors/david/), setting up the experiment and checking that the result works. It began as a quick feasibility check: how well can Claude Cowork **independently** set up a working website? The larger question behind it comes from a course on *Applied Agentic AI*: could a non-technical student get a real, free, maintainable website out of an AI agent over a few working sessions?

## The rules of the experiment

- **Free hosting only.** The site is a static website served by GitHub Pages at no cost.
- **Every change goes through the agent.** Text, layout, configuration and deployment are done by Claude, on request, in plain language.
- **The human does only what the agent may not:** creating accounts, handling secrets such as access tokens, granting permissions, and checking that the site works: that it is reachable, the links work and the text is readable.
- **All text is model-written.** The human did not write or edit any page. What you read is Claude's text, checked for function, not line-edited for content.
- **Friction is data.** Every point where things got stuck is written down, because that is what students will hit too.

## Status

The feasibility check is done. Within a single working session the site went from an empty folder to live, with an update loop that works (ask for a change → it's online a minute or two later). What came up along the way is on the [workflow page](/workflow/#friction-log-so-far).
