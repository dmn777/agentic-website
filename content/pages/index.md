This site is an experiment. It was planned, written, built and deployed by Claude, working as an agent inside **Claude Cowork**, with one human — [David](/authors/david/) — acting as lead QA and responsible human. It is also a dry run for a guided student project in a course on *Applied Agentic AI*: can a non-technical person get a real, free, maintainable website out of an AI agent over a few working sessions?

## The rules of the experiment

- **Free hosting only.** The site is a static website served by GitHub Pages at no cost.
- **Every change goes through the agent.** Text, layout, configuration and deployment are done by Claude, on request, in plain language.
- **The human does only what the agent may not:** creating accounts, handling secrets such as access tokens, granting permissions, and deciding what is good enough to publish.
- **Friction is data.** Every point where things got stuck is written down, because that is what students will hit too.
