# Agentic Website

A small static website built and maintained by Claude (via Claude Cowork) with a human in the loop.
Live: https://dmn777.github.io/agentic-website/

- Content: Markdown in `content/`
- Build: Astro (`npm run build`)
- Deploy: GitHub Actions → GitHub Pages on every push to `main`

See the site's "How it works" page for details, and `FRICTION_LOG.md` for what went wrong along the way.
